# TMDB-Movie-Analytics

## Overview
This project analyzes TMDB movie data using Python, SQL, Pandas, Seaborn, Matplotlib, SQLAlchemy, and Streamlit. The project includes data cleaning, SQL analysis, Pandas analysis, visualizations, and an interactive Streamlit dashboard.

## Files Included
01_data_cleaning.ipynb
02_sql_analysis.ipynb
03_pandas_analysis.ipynb
04_visualizations.ipynb
app.py
data/ (CSV files and movies.db)

Revenue and Genre Analysis
### Query Explorer
10 SQL Queries
Query Result Tables
Visualizations

#### Key Insights
Most movies have low to medium budgets.
Higher budgets generally lead to higher revenue.
Action, Drama, and Comedy are the most common genres.
Most movie ratings fall between 6 and 8.
